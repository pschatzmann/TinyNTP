TinyNTP Directory Reference

Files

 		TinyClockTimeSource.h
 Time source for the TinyNTPServer that you set from any source (RTC, GPS, ...) and that keeps running with millis().
 		TinyNTPClient.h
 Simple NTP client for Arduino using a generic UDP Client (e.g., WiFiUdp, EthernetUdp). It provides the UTC time and, with a POSIX TZ string, the local time including summer/winter time. The client is also a TinyTimeSource for the TinyNTPServer.
 		TinyNTPServer.h
 Simple NTP server for Arduino using a generic UDP class (e.g. WiFiUDP, EthernetUDP). It answers the requests of NTP clients with the time of a time source, e.g. a TinyNTPClient.
 		TinyNTPServers.h
 Defines for well known public NTP servers.
 		TinySHA256.h
 Small, portable SHA-256 and HMAC-SHA256 (FIPS 180-4, RFC 2104).
 		TinySystemTimeSource.h
 Time source for the TinyNTPServer that uses the system clock (e.g. set by the SNTP client of the ESP32/ESP8266 core).
 		TinyTimeSet.h
 Messages to set the time of a TinyNTPServer over the network.
 		TinyTimeSource.h

 		TinyTimeZone.h
 Portable parser for POSIX TZ strings (e.g. "CET-1CEST,M3.5.0,M10.5.0/3") that converts UTC to local time, including summer/winter time. It does not depend on tzset()/localtime_r().
