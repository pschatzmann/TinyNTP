Detailed Description

template<typename UDPAPI>
class tiny_ntp::TinyNTPServer< UDPAPI >

A minimal Network Time Protocol (NTP) server (RFC 5905, mode 4) that serves the time of a time source to the clients in your network.

The time comes from a TinyTimeSource, e.g. a TinyNTPClient (without a time offset or time zone), a TinySystemTimeSource or a TinyClockTimeSource. While the time source returns 0 (time not known), requests are not answered.

The server can optionally allow to set the time of the time source over the network, see enableTimeSetting().

The server does not block: call process() in your loop(). The answered clients can be limited to IPv4 subnets (setAllowedSubnets()) and to a number of requests per minute (setRateLimit()). Do not make it reachable from the internet.

The header of the answers (leap indicator, stratum, reference id, root delay and dispersion, precision) can be set to describe the quality of the time source, e.g. when it is disciplined from other servers.

If the same device also runs a TinyNTPClient, the client must not use port 123 as local port: call TinyNTPClient::setLocalPort().

◆ enableTimeSetting()

template<typename UDPAPI>
void tiny_ntp::TinyNTPServer< UDPAPI >::enableTimeSetting ( const char * secret)
inline

Allow to set the time of the time source over the network, e.g. with the command line tool tinyntp set. The requests are authenticated with HMAC-SHA256 and the secret, which is never sent over the network, and cannot be replayed. It is off by default and needs a time source that implements TinyTimeSource::setTimeMs() (e.g. TinyClockTimeSource).

Keep in mind that everybody who knows the secret can change the time that you serve: use this in a trusted network only.

Parameters
secretThe shared secret (a long random text). The text is not copied: it must stay valid as long as the server is used.
