Detailed Description

Dictionary of cities and their POSIX TZ strings. The entries are provided by the caller as an array, which is not copied: it must stay valid for the lifetime of the object (e.g. a global const array).

A city can be looked up with the full name ("Europe/Zurich") or just the city part ("Zurich"). The search ignores the case and treats a space like an underscore.
