Detailed Description

template<typename UDPAPI>
class tiny_ntp::TinyNTPClient< UDPAPI >

A Network Time Protocol (NTP) client for retrieving the current date/time from an NTP server using an Arduino UDP API. The time of the server is corrected by half of the network delay, and between the updates the time is calculated with millis(), corrected by the measured speed of millis() (see getMillisCorrectionFactor()).

The client provides the UTC time (getTimeMs(), getTimeSec(), getTm()) and, with a POSIX TZ string, the local time including summer/winter time (setTimeZone(), getLocalTm()). It is also a TinyTimeSource, so a TinyNTPServer can serve its time.

The functions block until the server has answered or the timeout has passed. Without a response, the request is sent again every 300 ms (some WiFi networks lose responses or hold them back until the device sends). Call update() from time to time (e.g. once per hour).
