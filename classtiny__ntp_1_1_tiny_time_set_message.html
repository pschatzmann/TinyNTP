Detailed Description

The messages of the protocol that sets the time of a TinyNTPServer (e.g. with the command line tool tinyntp set).

NTP has no way to set the time of a server, so the messages use the NTP mode 7 (reserved for private use) on the port of the server. A normal NTP client never sends them. The messages are authenticated with HMAC-SHA256 and a shared secret; the secret itself is never sent:

  1. Challenge request (client): header, type=1
  2. Challenge response (server): header, type=2, nonce[8]
  3. Set request (client): header, type=3, nonce[8], timeMs[8], hmac[32] where hmac = HMAC-SHA256(secret, type, nonce, timeMs)
  4. Set response (server): header, type=4, status, timeMs[8] (the time of the server after the request)

The server accepts a nonce only once and for a short time, so a recorded request cannot be replayed. All numbers are big endian.
