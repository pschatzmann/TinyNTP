Detailed Description

The UTC time of a GPS / GNSS receiver as time source, e.g. for a stratum 1 TinyNTPServer.

Feed the characters of the receiver with process() (or feed()). Each RMC or ZDA sentence sets the time; between the sentences it runs with micros().

  • With PPS: call pps() from the interrupt of the PPS pin. The rising edge is the start of the second that the following sentence reports, so the time is exact to a few µs.
  • Without PPS: the arrival of the first character of the sentence is used, corrected by setLatencyMs() (receiver specific, typically 50-500 ms): good to tens of ms.
TinyGPSTimeSource gps;
void IRAM_ATTR onPps() { gps.pps(micros()); }
void setup() {
Serial1.begin(9600);
attachInterrupt(digitalPinToInterrupt(PPS_PIN), onPps, RISING);
server.begin(gps);
server.setStratum(1);
server.setReferenceId("GPS");
}
void loop() {
gps.process(Serial1);
server.process();
}
