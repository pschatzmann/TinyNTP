Detailed Description

A software clock: you set the UTC time with setTime() and it keeps counting with millis(). Use it as time source of the TinyNTPServer when the time comes from a device that has no ready made getTimeMs(), e.g. an RTC chip or a GPS receiver:

clock.setTime(rtc.now().unixtime());
server.begin(clock);

As long as the time has not been set, getTimeMs() returns 0 (not known). millis() is not as exact as an RTC or a GPS: set the time regularly (e.g. every few minutes). It must be set or read at least once every 49 days because of the overflow of millis().
