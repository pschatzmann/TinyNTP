Detailed Description

Table of the IANA time zones and their POSIX TZ strings, to look up a zone by its name at runtime (e.g. a name that the user selected):

const char* tz = findTimeZone("Europe/Zurich"); if (tz != nullptr) ntp.setTimeZone(tz);

Not included by TinyNTP.h: the table needs about 15 kB of flash. Use the TZ_* defines of TinyTimeZones.h if the zone is known at compile time.
