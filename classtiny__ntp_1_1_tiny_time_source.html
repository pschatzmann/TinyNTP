Detailed Description

Abstract base class of all time sources: an object that knows the current UTC time. The TinyNTPServer serves the time of a TinyTimeSource.

Provided time sources: TinyNTPClient (time from the internet), TinySystemTimeSource (system clock) and TinyClockTimeSource (software clock that you set from an RTC, a GPS, ...). To use another source, derive from this class:

class MyTimeSource : public TinyTimeSource {
public:
uint64_t getTimeMs() override { return myClock.unixMs(); }
};

◆ getTimeMs()

virtual uint64_t tiny_ntp::TinyTimeSource::getTimeMs ( )
pure virtual

Get the current UTC time in milliseconds since 1970-01-01. It is called for each request, so it should be fast and must not block.

Returns
The time in ms, or 0 as long as the time is not known (e.g. not synchronized yet). The server does not answer while the time is 0.

Implemented in tiny_ntp::TinyClockTimeSource, tiny_ntp::TinyNTPClient< UDPAPI >, and tiny_ntp::TinySystemTimeSource.
