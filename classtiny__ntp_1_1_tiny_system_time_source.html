Detailed Description

Serves the UTC time of the system clock (gettimeofday()). It is available on the platforms that provide gettimeofday() (e.g. ESP32, ESP8266, RP2040, STM32, desktop) but not on AVR.

The system clock starts at 1970 when it has not been set: until the clock has a time after the "minimum valid time", the time is reported as not known (0).

configTime(0, 0, "pool.ntp.org"); // ESP32: set the clock with SNTP (UTC)
TinySystemTimeSource source;
server.begin(source);
