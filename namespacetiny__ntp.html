Detailed Description

The classes of the TinyNTP library: the NTP client (TinyNTPClient), the NTP server (TinyNTPServer), the time sources (TinyTimeSource) and the time zone handling (TinyTimeZone). TinyNTP.h uses the namespace automatically, unless NO_TINY_NTP_NAMESPACE is defined.
