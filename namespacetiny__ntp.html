Detailed Description

The classes of the TinyNTP library: the NTP client (TinyNTPClient), the NTP server (TinyNTPServer), the time sources (TinyTimeSource) and the time zone handling (TinyTimeZone). In Arduino sketches (ARDUINO is defined) the namespace is used automatically.
