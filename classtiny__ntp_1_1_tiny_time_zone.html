Detailed Description

Parses a POSIX TZ string and converts UTC time to local time.

Supported format: std offset [dst [offset] [,start[/time],end[/time]]]

  • names: 3 or more letters, or any text in <...> (e.g. <+0330>)
  • offset: [+-]hh[:mm[:ss]] (positive is west of UTC, as in POSIX)
  • rules: Mm.w.d (month, week 1-5 where 5 is last, weekday 0=Sunday), Jn (day 1-365 without leap day) or n (day 0-365 with leap day)
  • time: [+-]hh[:mm[:ss]], default 02:00:00 If a DST name is given without rules, the US rules (M3.2.0,M11.1.0) are used.
